# Example restraint-analysis results

These are pre-computed results, so the restraint page can be tried without running
LS-DYNA and without the large binout files.

- **Simulation:** VIVA+ 2.0.1 50M seated occupant in the Generic cockpit, frontal
  load case at 70 km/h, 150 ms (Test_Run_16, MPP double precision).
- **Produced by:** `python -m restraint_system_analysis.hbm RUN_DIR MAIN_KEY MODEL_DIR`
  with this version of HIVE.
- **Contents:** the Dynasaur definition files (`*.def`) generated by HIVE, the Dynasaur
  output CSVs, the values HIVE derives in Python, and `restraint_hbm_status.json`.
  Local paths have been removed from `restraint_hbm_status.json`.

## How to open them

- **From the GUI:** click "Run restraint system analysis", then click
  **"Open example results"** in the input window.
- **On the restraint page:** click **"Load example results"**.

Re-create the files after any change to the criteria definitions, so the example
stays consistent with the code.
